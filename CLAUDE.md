# Notes for coding agents

Plain static site, no build step. Serve the folder (VS Code Live Server) and edit files directly.
Target: Lenovo Tab K11 (Chrome, 1920×1200, Mali-G52). Keep frames under ~16 ms; world redraws only when something moves (30 fps cap for ambient life).

- Chapters live in `js/main.js`: S1–S4 story, G1–G7 game. `play(i)` jumps; `preset(i)` sets state for a jump. The ≡ jump menu only exists with `?review` in the URL.
- Run results come from `outcome()` (deterministic). Wheel spin is always distance ÷ radius.
- World units: 1 su = "10 cm". Wheels r = 0.159 su (10 cm/turn) and 0.239 su (15 cm/turn). Hanging rope = 12 su (120 cm).
- Camera: `camTo`, `camPath`, `crane` (GSAP). Nudges: `nudge(el,{tip,key})` — glow/pulse on where to tap; tips show once per session.

- Audio: `sfx` one-shots play Kenney CC0 samples from `assets/sfx/` (variations + pitch jitter, synth fallback; motor/squeal/whoosh/shutter stay synthesized). Success-only stings: `sfx.sting()` tower clear, `sfx.bright()` exact prediction, `sfx.fanfare()` finale — only rising jingles (never a 'lose' sting). Captions/questions auto-narrate their recorded line (`narrate`); tap the line itself to replay (no speaker sticker per line).
- Audio (cont.): `sfx` = one-shot sounds; `mood` (sfx.js) = synthesized ambience + music bed (`mood.bed(level)` 1–5 rises per tower lit, `mood.duck` under voice). Read-aloud: `speak(text,id)` plays `assets/voice/<id>.mp3`, falls back to browser speech.
- Set pieces: S4 `lookCloser()` (zoom into the wheel/rope contact, story only), G5 `blueprint()`, G7 `snapPostcard()`, sunrise via `maybeSunrise()` (only at calm beats), tower clear = cable pulse + `sparkTo()` tracker.
- UI shell = Figma "SKAI final" › entrepreneur (618:12456), assets in `assets/ui/skai/` (WebP, rebuilt transparent from the Figma layers). Exit+brand panel (tap twice → title), sound note → Replay Narration / Mute All Sounds, info note → current goal (never a hint), timer frame = clock, progress rail = checks (2 segments each) + points, hint note fixed bottom-left (close-up sits right of it, compact while choosing; G6 tray starts right of it), one tip on screen at a time, sound note also holds Full Screen, info note holds the goal + "Your guess", all CTAs use the riveted orange `.btn` plate (Fredoka One). Fonts: Fredoka One, Fredoka 700, Chakra Petch 700, Nunito.
- Look: cover = `world.cover` + `world.bg` (background framed separately); hill face has footpath, `FLOWERS`, cloud shadows; bot halo + contact glow + `cableDust`; `glossDisc` on metal wheels; depth haze; warm morning light (`warmA`, from 6:20); SKAI paper/tape panels and sticky title cards. All are cheap per-frame fills/sprites — keep it that way on the Mali.
- Mission clarity (learning-objective pass): S1 ends with `missionBrief()` (the problem statement: route + YOU FIX turn·wheel·load + 4-min cost, read by `s1_mission`). `routeHTML(cur)` draws bot → Towers 1–4 → Top → 7:00 and is reused on every tower title card (`banner(..., {route, fix})`) as "you are here". Each tower: `towerLoop(..., {ask, found})` shows the step question while setting up (hidden during runs) and a FOUND card (icon of what worked) after a clear; FOUND lines report what happened, never the rule (that stays for G5). End card recap `LEARNT` = one line per objective. Tray tips that only repeat the question were removed (glow kept).
- Spotlight (focus pass): `spotlight(at,{r})` dims the scene and leaves one soft pool of light on a world point (r in world units; glides if already on), `spotOff()`. `#spot` is one box-shadow element moved by transform only, under `#pins`/`#ui` so labels stay bright. `partTag(at,{icon,name,line})` = the part's name in plain Grade-4 words beside the light; `meetPart()` = light + tag + voice (`p_turn/p_wheel/p_load/p_tape`) at the start of each tower, naming the part only, never the setting. Used at story beats, tower set-up, G4 flag, G6 new bot; never during runs or replays. HUD focus (Tower 3 job card) uses `#dim`.
- Infographic pass: run diary `diaryOpen/diaryAdd` (top-left, "what you set → what the bot did", yellow ring = changed setting; `S.diary` also feeds G5 `blueprint()` field notes). G4 = "once around the wheel": the rim colour peels onto the cable (`world.ribbon.peel`, `drawPeel` in world.js, colours `RIBBON_COLS`) and each turn adds a block in the `#bars` bar model; camera follows close while turning, pulls back after; the predict question sits inside the stepper box. Outcome sheet pictures loop the motion they name (CSS). S4 `compareCard()` = station vs bot side by side. FOUND = sticker with a picture equation. Set-up framing: `towerLoop` pushes in on the bot (`setupView`), the run's follow-cam takes over (`camTw` killed). Hint note shows only after the first run of a step (`S.hintReady`); points box hidden until points exist.
- SKAI template pass (Drive "1st Prompt for Self Mission" / "Codex Prompt For Rework"): narration lock = `voLock` — the first auto-read of an instruction (`narrate` → `speak(...,{auto:true})`) dims + blocks `LOCKED` (tray options, stepper, rules, RUN, pins, NEXT) until the line ends, then `readyPulse()`; nudge glows wait for it; sound-note replay never locks. Hint note also appears after 8 s with no tap at a set-up step (`armIdleHint`), still only given on request. End card = what you did (run count) → What you found out (`LEARNT`) → `BIG_IDEA`, read by `end_recap`. Kept the brief over the template where they clash: story clock (not 00:00 count-up), no 3-strike reveal on tower runs, no "try again" wording.
- Declutter pass (≥30% fewer on-screen items/words, measured per screen): contextual HUD `hudOff()` — clock + rail hide during story S2–S4, title cards (`banner`), the outcome sheet, Say the Rule and the ride/end card (`endmode` also hides the info note); "First ride 7:00" shows only when time is added (`showDue`); points box flashes on gain (`flashPts`). No speaker stickers (line = replay), no first-time tips that repeat a visible button (kept: hotspot "Tap here", "Tap to turn the wheel once"). Route labels only Top/7:00 in the brief, none on title cards. Diary: no icon/numbers/cell tiles, fades before FOUND. FOUND lines drop "Tower N checked." G5: tapping a sentence picks + reads it. G6 tabs: icon-only unless open. Game name only on the title screen.
- Layout: 1600×1000 is the SAFE AREA, always fully visible; the stage grows to fill the window (`SW`×`SH`, `world.W/H`). Anchor UI to edges or `50%`, never hardcode 1600/1000 (use `SW`/`SH`). Check 1280×800 (K11), 1920×1080 and 1024×768.
- Images: all WebP. Keep each about 1.2× its largest on-screen size (kid sheets 162×216 frames, HUD icons ≤128 px); `PRELOAD` decodes everything behind the title before Start.
- Start screen plays `assets/video/intro_loop.mp4`; while it covers the stage `world.hidden` skips canvas drawing.

Brief rules (don't break):
- After a failed run: neutral replay + outcome tap only. No praise, no "try again", no auto-hint. Hints only on request (+2 min).
- Clock: failed run +4 min, tower cleared +4, Tower 4 check run +2; on-time star if the top is cleared by 7:00.
- Nudges point to where to tap, never to the right answer.
- Never say the pulley "makes lifting easier"; never claim real ropeways are inspected by bots. Operator appears in story slides only.
